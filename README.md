A 4 KB Python chess engine for make.fun's tiny-chess-01 bounty: alpha-beta search with a
transposition table, killers, late move reductions and a quiescence search, packed into an
LZMA payload so the whole entrypoint fits in 4,096 bytes.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8000 python main.py
```
